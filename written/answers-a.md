## 计算与简答（30 分）

### A11（6 分）

- `16000 × 2 × 1 = 32000 B/s`（1 分）。
- `3200 / 32000 = 0.1 s = 100 ms`（1 分）。
- `4 × ceil(3200/3) = 4 × 1067 = 4268` 个 Base64 字符（2 分）。
- 这是负载与覆盖时长计算，尚未计入排队、网络、推理、播放及消息开销，不能当成端到端延迟（2 分）。

### A12（6 分）

I2C：地址及其表示方式、总线速率、引脚/上拉等任答两项（2 分）。SPI：CPOL/CPHA 模式、频率、片选、字长等任答两项（2 分）。匹配成功不证明供电、复位、时序、寄存器协议及数据转换正确，应读取已知 ID 或做最小功能测试（2 分）。

### A13（6 分）

低优先级 L 持锁，高优先级 H 等该锁，中优先级 M 持续抢占 L，使 L 无法及时释放锁（3 分）。支持优先级继承的 mutex（1 分）；缩短临界区或通过资源所有者任务串行访问（1 分）；指出继承不能修复死锁，且需核对 RTOS 实现（1 分）。

### A14（6 分）

按已经成功取得的资源逆序回滚，不释放尚未申请成功的资源（2 分）；设备尚未注册成功时不能当作已注册设备无条件注销（1 分）。先阻止新事件，再同步停止中断、定时器、工作项等异步访问，最后释放其使用的数据，避免释放后使用（2 分）。`devm_*` 可管理部分资源，但不自动替你设计异步回调生命周期，且不能与手动释放重复（1 分）。

### A15（6 分）

共享谓词由同一把锁保护（1 分）。条件等待原子释放锁并等待，返回时重新持锁（2 分）。虚假唤醒、多个消费者竞争或状态变化要求重新检查谓词（2 分）。退出时更新 `stopping` 并唤醒等待者，定义是否排空已有数据（1 分）。

## 代码审查（20 分）

### A16（10 分）

局部数组返回后生命周期结束（3 分）；`strcpy` 未检查长度，可能越界（3 分）；未定义空指针、源串终止及截断策略（2 分）。推荐调用方传入 `char *dst, size_t capacity, const char *src`，约定源为有效 NUL 结尾字符串、对象不重叠、返回成功/截断/参数错误；容量大于零时保证结果有终止符（2 分）。

也可返回动态分配对象，但必须说明失败处理及由谁释放；仅改为静态数组会引入共享状态和不可重入问题，不应给满分。

### A17（10 分）

`used + len` 可能按 `size_t` 回绕，绕过检查（3 分）。先检查 `used <= cap`，再判断 `len <= cap-used`（3 分）。还需约定 `dst` 指向至少 `cap` 字节有效对象、`src` 对非零 `len` 指向足够可读对象、有效区域不重叠；如果允许重叠，使用 `memmove`。零长度策略要避免对空指针做运算或调用内存接口（2 分）。明确函数是否返回已用长度或由调用方更新；全部检查应发生在写入之前（2 分）。

示例核心逻辑如下，无法只凭一个指针和容量在运行时证明其真实对象大小：

```c
if (used > cap || len > cap - used) return -1;
if (len == 0) return 0;  /* 此路径不做指针运算 */
if (dst == NULL || src == NULL) return -1;
memcpy(dst + used, src, len); /* 调用方保证真实大小与不重叠 */
return 0;
```

## 算法设计 A18（20 分）

使用左闭右开区间 `[lo, hi)`，求第一个不小于 `key` 的位置，最后检查是否等于目标：

```c
size_t first_match(const int *a, size_t n, int key)
{
    size_t lo = 0, hi = n;
    while (lo < hi) {
        size_t mid = lo + (hi - lo) / 2;
        if (a[mid] < key) lo = mid + 1;
        else hi = mid;
    }
    return lo < n && a[lo] == key ? lo : n;
}
```

约定 `n>0` 时 `a` 指向至少 `n` 个有效且按非递减顺序排列的整数，`n=0` 时允许空指针。循环区间和推进正确（6 分），重复值返回首个匹配（4 分），中点与空数组安全（4 分），复杂度正确（2 分），测试覆盖空数组、首尾、重复、找不到/范围外等至少四类（4 分）。

另一个独立参考实现在 [C 编程练习](coding.md) 中；接口返回方式可能不同，按各自契约调用。
