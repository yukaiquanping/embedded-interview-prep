### A09. I2C 设备树子节点中的 `reg` 通常表示什么？

## 二、计算与简答（5 题 × 6 分 = 30 分）

### A11. PCM 与 Base64

16 kHz、16 bit、单声道 PCM：计算每秒字节数、3200 字节覆盖时长，以及这 3200 字节单独做 Base64 后的字符数。不计换行和消息外壳。说明这些值是否等于实际端到端延迟。

### A12. I2C 与 SPI

列出各自两项关键配置，说明某个外设能枚举或 `probe` 成功为什么不一定表示业务数据正确。

### A13. 优先级反转

给出低、中、高优先级三个任务构成优先级反转的例子，以及两种缓解方法。

### A14. 资源释放

驱动依次申请缓冲、GPIO、中断、注册设备，第 4 步失败。描述回滚原则；若已启动定时器或工作队列，还应考虑什么？

### A15. 条件变量

消费者等待“队列非空”，为什么使用 `while (queue_empty && !stopping)` 而不是 `if (queue_empty)`？描述等待时锁的行为与退出条件。

## 三、代码审查（2 题 × 10 分 = 20 分）

```c
char *make_name(const char *src)

    char buf[8];

```

### A17. 长度检查与整数溢出

设 `dst` 实际容量为 `cap`，已有 `used` 字节，追加 `len` 字节。指出检查的缺陷，写出不会先发生加法溢出的验证条件，并说明调用契约。

```c
int append(unsigned char *dst, size_t cap, size_t used,
           const unsigned char *src, size_t len)
{
    if (used + len > cap) return -1;
    memcpy(dst + used, src, len);
    return 0;
}
```

写出 C 实现或足够明确的伪代码，要求：`O(log n)` 时间、`O(1)` 额外空间；`n=0` 不访问元素；不使用容易溢出的 `(lo+hi)/2`；说明合法内存前提。列出至少四个测试场景。
